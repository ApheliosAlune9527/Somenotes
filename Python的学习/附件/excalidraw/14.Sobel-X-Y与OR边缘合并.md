Sobel X / Sobel Y：按方向提取边缘，再用 OR 合并 ^eh0001

核心理解 ^eh0003

Sobel X 问“从左到右亮度有没有突变”，所以抓垂直边缘；Sobel Y 问“从上到下亮度有没有突变”，所以抓水平边缘。 ^eh0004

两个方向各管一类边缘，最后用 OR 把任一方向出现的边缘并起来。 ^eh0005

步骤 1：Sobel X 只找垂直边缘 ^eh0007

sobel_x_float = cv.Sobel( ^eh0008

gray, cv.CV_64F, dx=1, dy=0, ksize=3) ^eh0009

sobel_x = cv.convertScaleAbs(sobel_x_float) ^eh0010

dx=1, dy=0：只算水平方向变化，像从左到右扫一行。 ^eh0011

左 → 右：暗  暗  暗  |  亮  亮  亮 ^eh0013

sobel_y = cv.convertScaleAbs(sobel_y_float) ^eh0033

理解：OR 不是继续求导，也不是增强亮度；它只是把 X 图和 Y 图里“有边缘”的地方并起来。 ^eh0071

为什么不用加法？ ^eh0073

加法会叠加强度 ^eh0075

200 + 200 = 400 → 截断 255 ^eh0076

容易过曝，边缘变成死白。 ^eh0077

OR 只做并集 ^eh0079

有 X 边缘 或 有 Y 边缘 → 保留 ^eh0080

不会把两个方向的强度相加。 ^eh0081

注意：OR 是按位合并，不是严格的数学加法；用于边
缘图合并时，直觉上就是“任一方向有边缘就留下”。 ^eh0082
