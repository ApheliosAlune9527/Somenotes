核心：II(x,y) 保存“从左上角到当前点”的累计像素和，所以矩形 D 不用遍历像素，只查 4 个角点。 ^eh0002

II(x2, y2) ^eh0016

四个积分图值分别代表什么 ^eh0017

II(x1, y1) = A ^eh0018

II(x2, y1) = A + B ^eh0019

II(x1, y2) = A + C ^eh0020

II(x2, y2) = A + B + C + D ^eh0021

把目标区 D 单独留下 ^eh0022

D = (A+B+C+D) + A - (A+B) - (A+C) ^eh0023

A、B、C 会被抵消，最后只剩目标区 D。 ^eh0024

最终公式 ^eh0025

Sum(D) = II(x2, y2) + II(x1, y1) - II(x2, y1) - II(x1, y2) ^eh0026

为什么是 O(1)：不管 D 里面有 10 个像素还是 100 万个像素，都只读取 4 个积分图角点。 ^eh0027
