# 贝叶斯公式和全概率公式

> 简单说全概率公式是贝叶斯公式的分母

想象有两条河流（甲河、乙河）汇入同一个**大水库**：

- 甲河水质一般，带来的泥沙占一部分；

- 乙河水质较差，带来的泥沙占另一部分。

## 全概率公式在干嘛？（顺流而下）

水库管理员想知道：“两条河汇合之后，**水库里总共有多少泥沙？**”

- 做法：把“甲河带进来的泥沙”加上“乙河带进来的泥沙”，合在一起算总泥沙量。

- 这就是**全概率公式**：把各种可能的原因合并起来，算一个**总结果**。

## 贝叶斯公式在干嘛？（溯流而上）

质检员从水库里舀起一杯水，发现**这杯水里有泥沙（结果已知）**。质检员推了推眼镜问：“**这杯泥沙，有多大可能是从甲河漂过来的？**”

- 做法：

    $$\frac{\text{甲河贡献的泥沙}}{\text{水库里总共有多少泥沙}}$$
- 这就是**贝叶斯公式**：在结果已知的前提下，反查具体是哪一条支流（原因）造成的。

# 概率论核心笔记：全概率公式与贝叶斯公式标准指南

## 一、前置核心概念：样本空间的划分（完备事件群）

无论是全概率公式还是贝叶斯公式，成立的数学基石都是对样本空间 $\Omega$ 的**划分（Partition）**。

### 1. 数学定义

设 $B_1, B_2, \dots, B_n$ 为随机试验的可能原因（或状态事件），若它们满足以下三个条件：

1. **两两互不相容（互斥）**：

    $$B_i \cap B_j = \emptyset \quad (\forall \, i \neq j)$$
2. **完备性（全覆盖）**：

    $$\bigcup_{i=1}^{n} B_i = B_1 \cup B_2 \cup \dots \cup B_n = \Omega$$
3. **非零概率**：

    $$P(B_i) > 0 \quad (i = 1, 2, \dots, n)$$

则称事件组 $\{B_1, B_2, \dots, B_n\}$ 为样本空间 $\Omega$ 的一个**划分**（又称**完备事件群**）。

> **大白话直观理解**：就像把一个大蛋糕完整切成了 $n$ 块，彼此不重叠、加在一起刚好是整块蛋糕，且每一块都有分量。

## 二、全概率公式（Law of Total Probability）

### 1. 核心思想

**“由因导果，分块求和”**。当直接计算全局事件 $A$ 的概率较困难时，把事件 $A$ 拆解到各个互不相容的分支 $B_i$ 上分别计算，最后加权累加。

### 2. 双事件标准版（最常用）

若事件 $B$ 与其对立事件 $\bar{B}$ 构成划分（例如：机器正常与故障、产品来自甲厂与乙厂），则对任意事件 $A$：

$$P(A) = P(B)P(A \mid B) + P(\bar{B})P(A \mid \bar{B})$$

若记作两个原因事件 $B_1, B_2$：

$$P(A) = P(B_1)P(A \mid B_1) + P(B_2)P(A \mid B_2)$$

### 3. $n$ 个事件通用标准版

设 $\{B_1, B_2, \dots, B_n\}$ 为样本空间 $\Omega$ 的一个划分，且 $P(B_i) > 0$。则对任意事件 $A$：

$$P(A) = \sum_{i=1}^{n} P(B_i)P(A \mid B_i)$$

展开形式为：

$$P(A) = P(B_1)P(A \mid B_1) + P(B_2)P(A \mid B_2) + \dots + P(B_n)P(A \mid B_n)$$

## 三、贝叶斯公式（Bayes' Theorem）

### 1. 核心思想

**“执果索因，逆推概率”**。在观察到结果事件 $A$ 已经发生之后，反向推算该结果是由特定原因 $B_k$ 导致的概率（从先验信念更新到后验信念）。

### 2. 条件概率定义形式（母公式）

由条件概率与乘法公式可直接推导：

$$P(B_k \mid A) = \frac{P(B_k \cap A)}{P(A)} = \frac{P(B_k)P(A \mid B_k)}{P(A)}$$

### 3. 双事件展开版

在已知结果 $A$ 发生的前提下，反推由原因 $B_1$ 引起的概率：

$$P(B_1 \mid A) = \frac{P(B_1)P(A \mid B_1)}{P(B_1)P(A \mid B_1) + P(B_2)P(A \mid B_2)}$$

### 4. $n$ 个事件通用标准版

设 $\{B_1, B_2, \dots, B_n\}$ 为样本空间 $\Omega$ 的一个划分， $A$ 为任意事件且 $P(A) > 0$。则对于任意一个特定原因 $B_k$（ $k = 1, 2, \dots, n$）：

$$P(B_k \mid A) = \frac{P(B_k)P(A \mid B_k)}{\sum_{i=1}^{n} P(B_i)P(A \mid B_i)}$$

> **结构记忆**：
>
> $$\text{贝叶斯公式} = \frac{\text{目标分支的乘积（分子）}}{\text{全概率公式算出的总概率（分母）}}$$

## 四、核心术语与现代统计学对照表

在概率论、数理统计以及机器学习（朴素贝叶斯、贝叶斯推断）中，公式中各要素的名称对应如下：

| 数学符号 | 中文规范名称 | 英文名称 | 直观含义 / 大白话解释 |
| --- | --- | --- | --- |
| $P(B_k)$ | **先验概率** | Prior Probability | 实验前、没有任何新观测时，根据历史经验得出的原因概率 |
| $P(A \mid B_k)$ | **条件概率 / 似然度** | Likelihood | 在假设原因 $B_k$ 成立的前提下，出现观测结果 $A$ 的可能性 |
| $P(A)$ | **全概率 / 证据** | Marginal Probability / Evidence | 结果事件 $A$ 在所有可能原因下发生时的总概率（归一化常数） |
| $P(B_k \mid A)$ | **后验概率** | Posterior Probability | 在已知观测到结果 $A$ 之后，对原因 $B_k$ 发生概率的更新修正 |

## 五、易错符号与运算细节辨析

### 1. 竖线 $\mid$ 的阅读规则

$$P(\text{目标事件} \mid \text{已知发生的前提})$$

- 竖线**右边**是**已经发生的背景条件**（空间被压缩到该条件下）；

- 竖线**左边**是**你要计算的目标事件**。

- 例： $P(B_1 \mid A)$ 是“已知 $A$ 已经发生，求 $B_1$ 的概率”。

### 2. 积事件（交 $\cap$）与条件概率（ $\mid$）的关系

- **乘法公式**：

    $$P(A \cap B) = P(B)P(A \mid B) = P(A)P(B \mid A)$$
- **区别**：

    - $P(A \cap B)$：在**全局范围**内，两件事情同时发生的比例。

    - $P(A \mid B)$：在**限定已经发生** $B$ **的局部圈子**里， $A$ 发生的比例。

## 六、考试与作业标准解题三步法

```
【标准解题三步法】

第 1 步：设事件
   - 设划分事件（原因）：B₁, B₂, ..., Bₙ 构成样本空间的一个划分
   - 设目标事件（结果）：A

第 2 步：列出题干已知概率
   - 写出先验概率：P(B₁), P(B₂), ...
   - 写出条件概率（似然）：P(A | B₁), P(A | B₂), ...

第 3 步：选公式计算并作答
   - 问“最终发生 A 的总概率” ──> 用全概率公式：
     P(A) = ∑ P(Bᵢ)P(A | Bᵢ)

   - 问“已知 A 发生，反求原因是 Bₖ 的概率” ──> 用贝叶斯公式：
     P(Bₖ | A) = [P(Bₖ)P(A | Bₖ)] / P(A)
```
